# 部署：登录 / 地址 / 订单（第 5 批）

新增需要在云开发后台操作的部分。其余前端代码工具部署即可。

## 1. 新建 3 个集合

云开发后台 → 数据库 → 「+ 新建集合」分别创建：

| 集合名     | 权限                                | 用途                       |
| ---------- | ----------------------------------- | -------------------------- |
| users      | 仅创建者及管理员可读写              | 微信用户档案（openid 主键）|
| addresses  | 仅创建者及管理员可读写              | 收货地址（一人一份）       |
| orders     | 仅创建者及管理员可读写              | 礼品申请（订单）           |

> 写入都靠云函数完成，不需要"所有用户可读写"。
> 「仅创建者可读写」=> 普通用户只能看见自己的 docs，云函数（管理员身份）可看所有。

## 2. 部署 2 个云函数

工具里右键 → 上传并部署：云端安装依赖

- `cloudfunctions/login`
- `cloudfunctions/submit-order`

部署完后两个云函数默认 3 秒超时，建议都改成 10 秒：
- 进入云开发后台 → 云函数 → 该函数 → 函数配置 → 执行超时时间 → 10 秒

## 3. 验证

### 登录
1. 模拟器点底部「我的」tab → 点头部「点击登录」
2. 进登录页 → 选头像 → 输昵称 → 提交
3. 应该 toast「欢迎」，回到「我的」，头部出现头像和昵称
4. 云开发 → 数据库 → users 集合应该多一条记录（openid + nickName + avatarUrl）

### 地址
1. 在「我的」点收货地址区
2. 进地址表单 → 填写 → 保存
3. 应该 toast「已保存」，回到「我的」，地址区域显示新内容
4. 云开发 → addresses 集合应该多一条记录

### 提交订单
1. 心愿单选 1-2 个礼品
2. 点「心愿单」tab → 滚到下方应该看到「📍 收货地址 + 备注框 + 提交申请」
3. 点「提交申请 (N 件)」→ 确认对话框 → 提交
4. 应该 toast「提交成功」→ 自动跳订单详情
5. 心愿单被清空
6. 云开发 → orders 集合多一条记录（status: pending）

### 我的订单
1. 「我的」→「我的订单」
2. 看见刚提交的订单卡片
3. 点进去 → 看见地址 + 商品列表 + 备注

## 4. 查看 / 处理订单（暂时手动）

在云开发后台 → 数据库 → orders 集合 → 直接看记录
- 按 createdAt 降序看新订单
- 改 `status` 字段：`pending` → `processing` → `done`（或 `cancelled`）
- 小程序里用户的「我的订单」会立刻看到状态变化

下阶段会做 admin.html 的「申请管理」面板，让你不用进云开发后台手动操作。
