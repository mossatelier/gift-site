# 部署：发货提醒（订阅消息）

用户提交订单时授权「发货提醒」；管理员录入快递单号时，云函数推送一条「已发货」订阅消息给用户。免费，个人主体小程序可用。

## 1. 申请「发货通知」模板

小程序后台 mp.weixin.qq.com → 功能 → 订阅消息 → 公共模板库 → 搜「发货」/「物流」→ 选一个「发货通知 / 发货提醒」模板 → 启用。

启用后会得到一个 **模板 ID**（一串字母数字），并能看到该模板的**字段列表**（如 thing1=商品、name4=快递公司、character_string5=单号、time2=发货时间，字段编号每个模板不同）。

## 2. 填模板 ID（两处，同一个值）

1. 小程序端：`miniprogram/config.js` → `shipNotifyTmplId: '你的模板ID'`
2. 云端：`miniprogram/cloudfunctions/admin-orders/index.js` 顶部 → `const SHIP_NOTIFY_TMPL_ID = '你的模板ID';`

## 3. 对齐模板字段（重要）

`admin-orders/index.js` 的 `sendShipNotify` 里 `data` 用的字段名（thing1 / name4 / character_string5 / time2）是**示例**。
必须改成你申请到的那个模板的**真实字段名**，否则推送会报错（errcode 47003）。
把你模板的字段截图发我，我帮你对齐；或自己按字段名一一对应修改。

## 4. 重新部署 admin-orders 云函数

工具里右键 cloudfunctions/admin-orders → 上传并部署：云端安装依赖。

## 5. 验证

1. 小程序提交一笔订单 → 提交时会弹「订阅消息」授权窗，点允许
2. admin 申请管理 → 给该订单录入快递单号 → 保存
3. 用户微信「服务通知」里应收到一条「已发货」提醒，点开跳订单详情

## 说明 / 限制

- **一次性订阅**：用户授权一次 = 能推一条。正好对应"发一次货推一次"。用户每次下单都会重新授权。
- 用户拒绝授权 → 不影响下单，只是收不到这条提醒。
- 模板 ID 没填时：前端不弹授权、云端不推送，功能静默关闭，不影响下单和录单号。
- 物流轨迹查询（第三方 API）因个人主体拿不到商用接口，未做；维持「复制单号自查」。
